# C言語レッスン

C言語はコンパイラ言語のためコンパイルが必要です。
VSCodeにターミナルがついているので、それを使ってコンパイルと実行をします。
VSCodeで「Control + Shift + `」 を押すことでVSCode内でターミナルを開けます。
そして以下2つのコマンドを打ち込みます。

(例)
gcc -o ファイル名(拡張子なし) ファイル名.c
./ファイル名(拡張子なし)


## プログラム実行手順

まずターミナルでこれをやる
```
gcc -o hello hello.c
```

次にターミナルでこれを実行すると、プログラムが走る
```
./hello
```
